Set up two-factor authentication

Your role requires a second step at sign-in: a 6-digit code from an authenticator app on your phone. It takes about a minute to set up.

  1. 1

    Install an authenticator app

    Google Authenticator or Microsoft Authenticator (free, App Store / Google Play). If you already use one, skip to step 2.

  2. 2

    Scan this QR code

    In the app tap + (or Add account) and choose Scan a QR code. The account appears as {{ issuer }} ({{ user.email }}).

    {{ qr_svg|safe }}
    Can't scan? Enter the key manually

    In the app choose Enter a setup key. Account: {{ user.email }}. Type of key: Time based. Key:

    {{ manual_key }}
  3. 3

    Enter the code the app shows

    The code changes every 30 seconds. Type the current one to confirm the setup.
